# Code of Conduct

Week HP is a GNOME Shell extension, and this project follows the
[GNOME Code of Conduct](https://conduct.gnome.org/).

It applies to everyone taking part in this project: issues, pull requests,
translations, reviews and any other discussion in this repository.

## Reporting

If you experience or witness unacceptable behavior in this repository,
please contact the maintainer privately through
[GitHub](https://github.com/asterion) instead of opening a public issue.

For incidents in GNOME spaces, such as extensions.gnome.org or GNOME chat
channels, follow the reporting process described at
[conduct.gnome.org](https://conduct.gnome.org/).
